# templates/note-template.md — note記事テンプレート

> 使い方：このファイルをコピーして記事ごとにファイルを作る。
> `【】`で囲まれた部分を実際の内容に差し替える。
> 差し替え前に成果物定義（As-Is / To-Be / 合格基準）を確定させておく。
> 最終更新：2026-06-29

---

## 記事メタ情報（公開前に必ず埋める）

```
タイトル：
テーマ：
型：A（実装ガイド）/ B（原則エッセイ）
対象読者層：A（未着手）/ B（未設計）/ C（未仕組み化）
As-Is（読者の現状）：
To-Be（記事後の状態）：
合格基準（「これができたらOK」）：
対応するX長文記事（あれば）：
note記事URL（公開後に記入）：
日付：
```

### Block 3：計測・検証

**合格基準**

【「これができたらTo-Beに達した」と判断できる具体的な状態を書く。
  数値や観察できる状態で表現する。「なんとなくできた気がする」はNG】

**計測フォーマット**

| 項目 | 計測方法 | 判断基準 |
|---|---|---|
| 【計測項目1】 | 【どう測るか】 | 【合格・要改善の基準】 |
| 【計測項目2】 | 【どう測るか】 | 【合格・要改善の基準】 |

**判断の基準**

- 【合格ライン】：→ 継続・他の業務にも展開する
